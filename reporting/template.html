06How to read this study

Completion and correctness are separateA timed-out workflow can leave code that passes tests. Conversely, passing the historical tests does not establish all requirements. Plan’s spooled-I/O implementation still materializes streams during equality despite passing the six historical checks.
Do not pool the two app phasesThe continuation resumes the same sessions and code with extra budget. Library follow-ups resume only exhausted arms; the calibration pilot is a separate selectable phase. Its effort columns are cumulative, not an independent replicate. Gennady ended blocked by infrastructure gates after planning; no feature implementation was submitted.
Reference provenance mattersThe three library fixes are historical human-authored changes; absence of AI assistance was not independently verified. Actual Budget’s reference PR explicitly declares AI assistance. Reference acceptance tests also helped define the task, so its own passing tests are not independent proof.
Coverage is evidence of executionPython counts added executable lines. TypeScript counts added lines starting an Istanbul statement, unioned across core and web tests. Neither is branch/path coverage or proof of good assertions. Unmapped files and missing observations are disclosed; N/A is not zero.
Budget and review limitationsOne trial per task/approach gives no confidence interval or general winner. Different workflow shapes hit per-stage caps differently. Model quality reviews are fallible and preceded later app browser adjudication. Later QA supersedes only the checks actually replayed.
Effort, cost, and reproducibility Local macOS isolation is a practical harness boundary, not a VM. The share archive preserves original text, including host paths and dialogue; review it before wider distribution. Dependencies and credentials are excluded.
